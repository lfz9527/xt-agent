# P2-3.2 Agent / Tool Executor

> P2-3.2 把真正的 Agent / Tool 调用接入 Execution Runtime，同时保持 Kernel 作为不可绕过的安全边界。

## 核心原则

```text
Agent / Tool
    ↓
StageHandler
    ↓
GuardedStageExecutor
    ↓
LoopRuntimeKernel
    ├─ Policy / Capability
    ├─ Approval
    ├─ Resource Policy
    ├─ Resource Lock
    ├─ Git Consistency
    └─ Mutation Journal
```

Agent 不应该直接修改 Runtime State、直接写项目文件或绕过 Capability Enforcement。

## 已实现

- `GuardedStageExecutor`：只执行显式注册的 Stage Handler。
- `executeAgentTool()`：把 Agent Tool 调用显式绑定到 Kernel Capability Enforcement。
- `mutate()`：为 Stage Handler 提供受保护的资源 mutation 入口。
- 未注册 Stage 默认 `[LOOP_BLOCKED]`，禁止隐式 fallback。
- Vitest 覆盖 Stage Dispatch、Unknown Stage、Agent Tool → Kernel 路由。

## 当前边界

P2-3.2 不负责具体 LLM Provider、Shell、Git、Vitest 等工具实现；这些属于 Tool Adapter 层。Runtime 只负责调度与安全约束。
