# 通用 Review 规则

适用于所有语言的基础规则。

## 正确性

- 检查逻辑、边界条件、状态转换和错误路径。
- 不把风格偏好当成 Bug。

## 安全

- 检查认证、授权、输入校验、注入、敏感信息泄露和不安全的外部输入处理。

## 并发与资源

- 检查异步任务、竞态、重复执行、取消、超时和资源释放。

## 数据

- 检查事务、一致性、幂等性、重复写入和异常恢复。

## 测试

- 判断变化是否需要新增或修改测试。
- 优先覆盖边界条件和回归场景。

## 复杂度

- 关注高复杂度、重复分支、深层嵌套和难以验证的逻辑。

## 重复

- 识别语义重复，而不是单纯文本重复。
- 新代码优先复用已有能力。

## 架构

- 尊重项目既有模块边界和依赖方向。
- 对跨层访问、循环依赖和职责泄漏保持警惕。
